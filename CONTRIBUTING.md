# Contributing Guidelines

## Development Principles
- Maintain clarity and stability in all modules.
- Preserve geometric consistency with SEFI and GWFM canon.
- Keep all modules dependency-free unless absolutely required.

## Code Style
- Use clean, readable Python.
- Avoid unnecessary abstraction.
- Document geometric reasoning where relevant.

## Pull Requests
- Describe the purpose of the change.
- Include tests when applicable.
- Ensure compatibility with existing pipeline orchestration.
